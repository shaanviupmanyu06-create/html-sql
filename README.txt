MEMBER PORTAL

This is a PHP and MySQL registration/login site with per-user blog post management for WAMP. It uses a MySQL database named blog and saves accounts and posts in the singular `user` and `post` tables. Account IDs are generated by MySQL; users choose a unique username and password. Signed-in users can create, view, edit, and delete their own posts.

Setup:
1. Start Apache and MySQL from the Wampserver tray menu.
2. Open http://localhost/phpmyadmin/ and import setup.sql, or paste its contents into the SQL tab. The script creates the blog database and singular `user` and `post` tables. The existing installation's accounts were migrated into `user`; the old plural `users` and `posts` tables are retained as backups and are no longer used by the site.
3. If your MySQL root account has a password, update $databasePassword in bootstrap.php.
4. Open http://localhost/login_site/ in your browser.

If you have forgotten all account passwords, run `Reset all account passwords.ps1` from PowerShell. It asks for one 6-digit numeric temporary password without displaying it, replaces every account password with its one-way hash, and requires each account to choose a new password at its next sign-in. Do not reuse the temporary password as a permanent password. This resets passwords; it cannot recover the old ones.

Passwords must be exactly 6 digits and are stored as one-way password hashes (they cannot be displayed or recovered as plaintext). Six-digit passwords are much easier to guess; use this policy only for a local/test site, not a public website. Each post is linked to its author, and post changes are restricted to that signed-in author. For a public production website, configure a dedicated database user, HTTPS, and production-grade error handling before deployment.
